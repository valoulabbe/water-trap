## DHS — API des indicateurs (agrégats nationaux)
API publique du DHS Program (`https://api.dhsprogram.com/rest/dhs/`), interrogée par le package R `rdhs` 0.8.1, **sans inscription**. Elle renvoie des **agrégats publiés** (indicateurs déjà calculés par le DHS Program, par enquête et par pays), **pas des microdonnées** : ni ménage, ni grappe, ni coordonnées. Les microdonnées et les fichiers GPS demandent une inscription séparée, non faite.

Tiré le 2026-09-27 par `code/12_dhs_api_inventaire.R` :
- `dhs_indicators()` : catalogue complet (4 655 indicateurs, dont 243 de la famille `WS_`) ;
- `dhs_data(breakdown = "national")` pour `WS_WTRT_H_CER` et `WS_SRCE_H_` `PIP`, `PYD`, `TAP`, `TUB`, `TNK`, `VND`, `BOT`, `SCH`, `IMP`, `PNB`, `POY` : 2 386 valeurs, tous types d'enquête (DHS 1 993, MIS 316, AIS 77) ;
- `dhs_datasets(fileType = "GE")` : la **liste** des fichiers GPS (261, dont 195 d'enquêtes DHS), pas les fichiers eux-mêmes.

Rien n'est rangé dans `raw/` : les tirages bruts sont dans `build/12_indicateurs.rds`, `build/12_donnees.rds` et `build/12_ge.rds`, et le cache `rdhs` dans `build/rdhs_cache/`. Les deux sont ignorés par git. `--force` refait les appels ; les valeurs peuvent alors changer si le DHS Program révise ses publications. Le programme DHS est arrêté depuis février 2025 (suspension USAID) ; l'API servait encore les données historiques à cette date.
